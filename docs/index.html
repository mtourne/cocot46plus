Dvorak, a trackball and ten thumb keys

QMK firmware for aki27's cocot46plus, a 46-key split keyboard with a trackball, a knob and an OLED. It types Dvorak on any computer, puts the modifiers under your fingers and moves everything else to the thumbs.

How it works

Dvorak on any computer

Two modes, saved on the keyboard. In DV the computer is set to Dvorak and the board sends ordinary keys. In QW the computer stays on US and the board sends Dvorak letters itself. Shortcuts follow the Dvorak letters in both: ⌘C is on the Dvorak C.

Modifiers on the home row

Hold a home-row letter for Ctrl, Alt, Cmd or Shift, in that order from the little finger. A key pressed within 200 ms of the previous letter always types its letter, so fast typing never triggers a modifier. Shift's window is 80 ms, so capitals still come easily.

NAV

Arrows, Home and End, page keys and four delete keys on the right hand. Undo, Cut, Copy, Paste and Redo on the left, with plain Ctrl, Alt, Cmd and Shift under the fingers for selecting with the arrows. The ball scrolls.

NUM

A numpad on the right, symbols on the left, and one rule: Shift gives the partner you'd expect. * and /, + and -, . and ,; [ sits under ( and gives {.

FUN

F1 to F12, volume and media keys, LED colour and brightness, trackball speed and angle, and the switches for Mac or Windows and DV or QW. The OLED names each setting as you change it.

MOUSE

Turns on by itself when the ball moves. Clicks sit on the home row of both hands, and the little fingers hold to scroll.

The thumbs, from the outside in

The left thumb deletes and the right one types. Layer keys switch only after a full hold, so a quick tap rolled into the next letter stays a tap.

Watch it live

The keyboard can report each key press over a separate USB channel, and only does while something is listening. Open the live view in Chrome and click Connect keyboard: keys light up as you hold them and the board follows the active layer. On a Mac, Cocot Live shows the same view in a small panel that floats over other windows, and shows the layer and held modifiers in the menu bar.

Build and flash

  1. Install the QMK CLI and avrdude.
  2. Clone this repo and run ./build.sh flash. The first run clones QMK 0.31.12 next to it.
  3. Start the bootloader: hold a green thumb key and the cyan key beside it, then press Boot (top left), or press the reset button twice.
git clone https://github.com/mtourne/cocot46plus
cd cocot46plus
./build.sh flash

Every push also builds the firmware on GitHub; the .hex is attached to each run.

The cocot46plus and its QMK board code are by aki27. This layout runs on QMK, borrows dual-use keys from dlip's engram layout and symbol ideas from Pascal Getreuer, and is drawn with keymap-drawer.
